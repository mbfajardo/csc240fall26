# CSC240 Class Project

## Overview
This repository will be used for my CSC240 class project. The project details and goals will be added as I learn more about the requirements.

Potential Project Ideas:
1. Beauty & Fragrance Collection Database
A database for organizing beauty products and fragrances by brand, category, price, scent notes, and personal ratings.
2. Gaming Database
A database for organizing video games, genres, platforms, personal ratings, and gaming progress.
3. Music Listening Tracker
A database inspired by music streaming platforms such as Spotify. It could organize songs, artists, genres, playlists, listening history, and personal music preferences.
